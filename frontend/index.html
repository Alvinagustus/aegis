🚀 Deploy Aegis (advanced — setup once via CLI)

Wallets block in-app contract deployment by design (it could hijack your account), so for your first setup use the one-command CLI instead:

./setup.sh <your-account> <contract-account> [reviewer] [guardian]

After that, everything below works from this page with your wallet — no CLI needed.

Policy (live from contract)

AI review verdicts (on-chain)

Verdicts are attested by the reviewer account after a model scores the intent inside NEAR AI Cloud's TEE. No verdict → transfer denied. Deny or risk ≥ 70 → denied even for whitelisted addresses.

Send a guarded transfer

1. Submit the intent to the AI reviewer agent (local CLI) so a verdict exists on-chain:

node tools/reviewer/review.mjs --submit '{"chain":"eth","to":"…","amount":"…","token":"ETH","memo":"…"}'

2. Fill this form (intent hash is computed here) → 3. Submit to the contract (wallet signature) → 4. If approved, sign via MPC.

Owner actions (operator only)

Guardian actions are done from the guardian's own wallet (panic_on / hold_escalate). Capsule + inheritance flows are in the CLI runbook (docs/deploy.md).

  2. Watchdog simulate_tx → Approve (whitelisted + within daily limit)
